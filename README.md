# Palworld Guide

팽월드 공개 공략집과 GitHub Pages 배포만 포함하는 독립 저장소입니다.

- 정적 사이트: `site/`
- 공개 자료 수집·정제: `scripts/`
- 검증: `npm test`
- 자료 갱신: `npm run refresh`

홈 서버 상태, 사용자 정보, IP 주소, 인증 정보와 Discord 설정은 이 저장소에 포함하지 않습니다.

운영 대시보드 소스는 [palworld-dashboard](https://github.com/kms0539/palworld-dashboard)에서 별도로 관리합니다.
