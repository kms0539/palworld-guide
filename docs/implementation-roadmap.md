이 문서는 Palworld 1.0 계열 공략 데이터를 단계적으로 확장하기 위한 작업 경계와 완료 조건을 정의한다. 각 작업은 앞 작업의 공개 데이터 계약을 재사용하며 한 번에 하나씩 진행한다.

## 공통 원칙

- 공식 패치 버전과 데이터 호환 범위를 분리한다. 현재 공식 확인 패치는 `1.0.3`, 데이터 호환 범위는 `1.0.x`다.
- 펠의 종, 아종·형태, 보스 전용 형태, 획득 가능 여부를 별도 필드로 표현한다.
- 모든 외부 데이터에는 출처 URL, 확인 시점, 게임 버전, 증거 등급을 기록한다.
- 공식 사실, 게임 추출 데이터, 계산 결과, 커뮤니티 검증, 편집형 추천을 구분한다.
- 외부 설명문을 복제하지 않고 사실 데이터와 자체 작성한 한국어 공략을 분리한다.
- 브라우저 개인 데이터는 서버로 전송하지 않고 로컬에만 저장한다.
- 공개 데이터 생성 과정에서 서버 상태, 사용자, IP, 인증 정보와 Discord 설정을 제외한다.

## Task 01 — 공통 데이터 계약과 출처 레지스트리

**우선순위:** P0
**선행 작업:** 없음

### 범위

- 공개 데이터셋의 ID, 경로, 스키마 버전, 필수 여부와 갱신 방식을 등록한다.
- `releaseLine`, `latestVerifiedPatch`, `dataCompatibility`를 분리한다.
- 증거 등급과 데이터 출처에 필요한 공통 필드를 정의한다.
- 등록된 JSON 파일과 실제 스키마 버전이 일치하는지 검증한다.

### 산출물

- `site/data/data-registry.json`
- `tests/data-registry.test.mjs`
- 이 로드맵 문서

### 완료 조건

- 모든 기존 공개 JSON이 레지스트리에 등록되어 있다.
- 경로 이탈과 중복 ID가 거부된다.
- 등록된 파일의 `schemaVersion`이 계약과 일치한다.
- 공식 버전 확인 URL과 날짜가 유효하다.

## Task 02 — 펠 상세 도감

**우선순위:** P0
**선행 작업:** Task 01

### 범위

- 펠과 형태를 안정적인 내부 ID로 정규화한다.
- 도감 번호, 획득 가능 여부, 속성, 기본 능력치, 이동 속도, 작업 적성, 식사량과 희귀도를 수집한다.
- 파트너 스킬, 액티브 스킬 습득표, 드롭과 출현 위치를 연결한다.
- 목록 필터, 정렬, 상세 화면과 최대 3마리 비교 기능을 제공한다.

### 완료 조건

- 이름이 아닌 ID로 모든 펠 데이터가 결합된다.
- 일반·아종·보스 전용 형태를 구분할 수 있다.
- 불완전한 필드는 추측값 대신 `null`과 출처 상태를 표시한다.
- 검색, 복합 필터와 비교 동작이 테스트된다.

## Task 03 — 번식·변이 계산기

**우선순위:** P0
**선행 작업:** Task 02

### 범위

- 1.0 번식 랭크, 특수 조합, 성별 확률과 번식 제외 조건을 수집한다.
- 부모→자식, 목표→부모 쌍, 보유 펠→목표 최단 경로를 제공한다.
- 특성·IV 계승, 변이와 케이크 효과를 별도 근거 수준으로 표시한다.
- 보유 펠 목록은 브라우저 로컬에 저장한다.

### 완료 조건

- 고정 검증 사례와 전체 조합의 대칭성이 테스트된다.
- 획득 불가 또는 번식 제외 형태가 경로에 잘못 포함되지 않는다.
- 계산 결과에 데이터 버전과 출처가 표시된다.

## Task 04 — 아이템·제작·기술 탐색기

**우선순위:** P0
**선행 작업:** Task 01

### 범위

- 아이템, 제작법, 제작 시설, 기술 해금과 획득처를 정규화한다.
- 최종 제작물에서 원재료까지 재귀적으로 펼치는 재료 계산기를 제공한다.
- 무기, 방어구, 음식, 설계도, 재료와 구조물을 검색·필터링한다.

### 완료 조건

- 순환 제작법을 탐지하고 무한 재귀를 방지한다.
- 제작 수량을 반영한 원재료 합계가 검증된다.
- 아이템에서 관련 펠, 지도 위치와 제작 시설로 이동할 수 있다.

## Task 05 — 지도 확장

**우선순위:** P0
**선행 작업:** Task 02, Task 04

### 범위

- 자원, 던전, 상인, 설계도, 일지, 수집물, 퀘스트와 야생 서식지를 추가한다.
- 지도별 좌표 변환과 레이어별 출처를 검증한다.
- 대량 스폰 데이터는 선택 기반 표시, 클러스터 또는 지연 로딩을 적용한다.
- 필터 상태를 공유 가능한 URL로 표현한다.

### 완료 조건

- 각 마커가 유효한 지도와 좌표 범위에 속한다.
- 기본 화면에서 대량 스폰 마커를 전부 렌더링하지 않는다.
- 검색 결과가 펠·아이템·보스 상세 화면과 연결된다.

## Task 06 — 보스 대응 도우미

**우선순위:** P1
**선행 작업:** Task 02, Task 04, Task 05

### 범위

- 알파, 타워, 레이드와 월드 보스를 분리한다.
- 속성 상성, 위치, 선행 조건, 보상과 설계도를 연결한다.
- 보유 펠 또는 전체 펠 기준으로 추천 파티와 대체 후보를 생성한다.
- 데이터 계산 결과와 편집자 추천 운용법을 분리한다.

### 완료 조건

- 보스 유형과 버전이 명확히 표시된다.
- 추천 근거가 능력치·스킬·상성 데이터로 추적 가능하다.
- 편집형 추천은 공식 사실처럼 표시되지 않는다.

## Task 07 — 거점 생산 플래너

**우선순위:** P1
**선행 작업:** Task 02, Task 04

### 범위

- 목표 생산물과 수량에서 시설, 재료와 작업 적성을 계산한다.
- 작업별 최소 인원, 대체 펠과 운반 병목을 제안한다.
- 번식, 채광·제작, 식량과 초반 거점 프리셋을 제공한다.
- 월드 설정에 영향을 받는 수치는 기본값과 사용자 입력을 구분한다.

### 완료 조건

- 작업 적성과 시설 요구 조건이 일치한다.
- 확인되지 않은 생산 속도는 계산값으로 노출하지 않는다.
- 결과를 재료 탐색기와 지도에 연결한다.

## Task 08 — 로컬 진행 체크리스트

**우선순위:** P1
**선행 작업:** Task 02, Task 05

### 범위

- 도감, 보스, 빠른 이동, 수집물, 던전과 설계도 진행 상태를 저장한다.
- 데이터 버전 변경 시 로컬 상태를 안전하게 마이그레이션한다.
- 내보내기·가져오기와 전체 초기화를 제공한다.

### 완료 조건

- 데이터가 브라우저 밖으로 전송되지 않는다.
- 잘못된 가져오기 데이터가 기존 상태를 덮어쓰지 않는다.
- 초기화 전 사용자 확인과 복구용 내보내기를 제공한다.

## Task 09 — 낚시·원정 정보

**우선순위:** P2
**선행 작업:** Task 02, Task 04, Task 05

### 범위

- 낚시터, 난이도, 미끼, 획득 펠·아이템과 관련 파티 스킬을 연결한다.
- 원정 임무, 요구 화력, 시간과 보상 풀을 제공한다.

### 완료 조건

- 확정 보상과 확률 보상을 구분한다.
- 1.0.3에서 변경된 월드 트리 성수 획득처를 반영한다.

## Task 10 — 로컬 세이브 분석

**우선순위:** P2
**선행 작업:** Task 03, Task 08

### 범위

- 1.0 세이브 형식과 지원 플랫폼을 먼저 검증한다.
- 사용자가 명시적으로 선택한 파일을 브라우저 내부에서 읽기 전용으로 처리한다.
- 보유 펠, 특성, IV와 진행 상태를 계산기·체크리스트에 연결한다.

### 완료 조건

- 파일을 네트워크로 전송하지 않는다.
- 원본 세이브를 수정하거나 덮어쓰지 않는다.
- 미지원 형식은 구체적인 이유와 함께 안전하게 거부한다.

## Task 11 — 패치 데이터 비교

**우선순위:** P2
**선행 작업:** Task 01 및 비교할 두 버전의 스냅샷

### 범위

- 공식 버전 확인과 대규모 데이터 갱신을 분리한다.
- 펠, 스킬, 번식, 아이템, 제작법과 지도 데이터의 버전 간 차이를 생성한다.
- 추가·삭제·변경과 출처 불일치를 검수 가능한 리포트로 만든다.

### 완료 조건

- 버전 변화가 없으면 외부 전체 수집을 실행하지 않는다.
- 변경 리포트가 검수되기 전에는 새 스냅샷을 공개하지 않는다.
- 이전 공개 스냅샷으로 되돌릴 수 있다.

## 구현 결과 메모

- 지도 확장 데이터는 기본 화면에서 비활성화하고 사용자가 레이어를 선택할 때만 그린다. 지도 지역·레이어·검색어는 허용 목록을 거쳐 URL로 공유된다.
- 보스 후보 점수는 상성 일치 펠의 `HP + 원거리 공격 + 방어력`만 합산한 계산 결과이며, 편집형 운용법과 분리했다.
- 생산 플래너는 확인된 제작법과 작업 적성만 사용한다. 확인되지 않은 생산 속도와 최소 인원은 계산하지 않는다.
- 진행 체크리스트와 세이브 파일은 브라우저 내부에서만 처리한다. 가져오기 데이터는 현재 데이터셋에 존재하는 ID만 보존한다.
- 세이브 분석은 현재 검증된 `PlZ` 컨테이너만 지원한다. 브라우저에 Oodle 해제기가 없는 `PlM`과 미구현 `CNK`는 구체적인 이유와 함께 거부한다.
- 비교할 이전 버전 스냅샷이 존재하지 않아 `1.0.3`을 최초 기준선으로 저장했다. 다음 공식 버전부터 추가·삭제·변경 리포트를 만들며, 검수 승인 전 공개하지 않는다.
