## 커밋된 정적 자료

아래는 매일 갱신하지 않습니다. 게임 패치로 수치가 바뀌거나 항목이 추가될 때만
손으로 갱신하고 커밋합니다. 매일 외부 사이트를 긁을 이유가 없고, 수집이 실패해도
사이트가 멀쩡히 뜨는 편이 낫기 때문입니다.

### `site/data/traits.json` — 특성 효과·등급·한국어

`pnpm run traits:refresh`로 갱신합니다. `palworld.tools`에서 효과와 등급을 받아
한국어로 옮기고, 아래 이름 스냅샷을 붙여 씁니다.

규칙에 없는 효과 문구가 하나라도 나오면 **실패합니다.** 패치로 새 문구가 생기면
`trait-korean.mjs`에 규칙을 추가한 뒤 다시 실행하세요. 영문이 조용히 공개되지
않게 하려는 장치입니다.

### `site/data/trait-names-ko.json` — 특성 한국어 이름

`palworld.gg`가 특성 목록을 **클라이언트에서 페이지네이션**합니다. 서버 응답에는
161종 중 60종만 담겨 있고 페이지 전환 시 네트워크 요청도 없어, 일반 요청으로는
전체를 받을 수 없습니다. 그래서 이 매핑만 브라우저로 모아 스냅샷으로 둡니다.

갱신 순서:

1. 브라우저로 `https://palworld.gg/passive-skills`와 `https://palworld.gg/ko/passive-skills`를 연다.
2. 각 페이지에서 1·2·3 페이지 버튼을 눌러가며 카드를 모은다. 카드마다
   이름, 등급 아이콘의 `rank_NN`, `p.descr`의 각 줄이 필요하다.
3. 두 목록을 `[이름, 등급, "효과1|효과2"]` 형태의 JSON 배열 두 개로 저장한다.
4. `trait-name-match.mjs`의 `matchBySignature`로 짝을 만든다. 효과를
   (능력치 토큰, 부호 있는 숫자)로 환원해 맞추므로 번역 표기가 달라도 대응된다.
5. 1:1인지, 모호한 짝이 없는지 확인하고 `names`에 기록한다.

두 언어 목록은 각자 언어 알파벳순이라 **순서로 짝지으면 안 됩니다.**
그렇게 하면 `Demon's Hand`가 `악마의 손`이 아니라 `선인`에 붙습니다.

이름을 확보하지 못한 특성은 영문 이름을 그대로 씁니다. 추측 번역은 넣지 않습니다.
`update-trait-catalog.mjs`는 커버리지가 60% 밑으로 떨어지면 실패하므로,
스냅샷이 낡으면 조용히 넘어가지 않고 드러납니다.
